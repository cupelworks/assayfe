Application under test

Editable soon · read from environment

The endpoint Assay calls for an answer when a test has no recorded model output. One Assay deployment tests one application. A change applies to future runs only - every run keeps the answer it actually scored, and a replay of an application-sourced run calls the application again with the current values.

Read-only

Deployment-level values, read once when a process starts. Changing any of them means restarting the API and/or the worker - they are shown so an operator can confirm what is running, never edited here. Connection strings are never displayed: they can embed credentials.
